# Git Befehle
 - **git config:** konfiguriert verschiedene Optionen wie Benutzername und E-Mail Adresse
 - **git init:** initialisiert ein Git Repository lokal
 - **git commit:** speichert alle veränderten und neu-hinzugefügten Dateien im Staging Bereich in die neue Version
 - **git status:** zeigt die Unterschiede zwischen den Dateien im Staging Bereich und dem Commit an
 - **git add:** fügt Dateien in den Staging Bereich des Repository
 - **git log:** zeigt Informationen über den aktuellen Commit an
 - **git diff:** zeigt die Unterschiede zwischen den Commits an
 - **git pull:** holt die aktuelle Version vom Server
 - **git push:** schickt die Dateien an den Server
 - **git branch:** erstellt einen neuen Zweig
 - **git checkout:** wechselt den Zweig
 - **git merge:** fügt zwei verschiedene Commitverläufe zusammen
