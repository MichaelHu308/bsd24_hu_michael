# Web Development for Beginners
Das "Web Development for Beginners" Curriculum ist ein umfassender 12-wöchiger von Microsoft Cloud Advocates. Es bietet 24 Lektionen, die sich auf die Grundlagen der Webentwicklung konzentrieren, einschließlich JavaScript, CSS und HTML.

Jede Lektion umfasst verschiedene Elemente wie optionale Sketchnotes, Videos, Quizze, schriftliche Lektionen, Projektanleitungen, Wissensüberprüfungen, Herausforderungen, ergänzende Lektüre und Aufgaben.
